## Project Overview

This repository holds the source code for **Zero Restriction** — the official online store for high-performance activewear and golf apparel, specializing in weather-ready, motion-optimized gear.

- Developed as a complete custom theme using Shopify Online Store 2.0 from a blank slate
- No usage of Dawn, Impulse, Prestige, or any premium/published theme as foundation
- All Liquid templates, sections, snippets, CSS, JS, and configuration were hand-authored
- Core focus: performance-driven UX, brand storytelling around innovation and durability, clean code architecture, and fast loading for a premium outdoor/sports audience

Live site: https://zerorestriction.com

## Key Custom Features

- Bespoke modular design system tailored to performance apparel presentation
- AJAX-powered collection filtering, sorting, and instant search
- Dynamic mega menu with activity-based previews (Golf, Pickleball & Tennis, Run & Train, etc.)
- Custom homepage sections: hero banners with messaging ("Defy the Forecast", "Innovation At The Core"), featured collections, browse-by-activity grids
- Advanced product media support: zoom, multiple angles, videos, performance tech badges
- Interactive size charts, how-to-measure guides, and universal sizing tables
- Custom collection layouts (grid, featured carousels, best sellers highlights)
- Sticky mobile navigation & quick-add functionality
- Enhanced cart drawer with upsell/cross-sell logic
- Technology showcase sections (Waterproof, Motion Tuned, Insulation, Windproof, Hybrids, Moisture Wicking)
- Branded trust elements: "Guaranteed Waterproof for Life", custom badges, policies
- Schema.org + JSON-LD structured data for products, collections, and organization
- Custom pages: 404, password, gift card, size chart, garment care, affiliate program

## Tech Stack

| Layer            | Technologies                          |
|------------------|---------------------------------------|
| Platform         | Shopify (Online Store 2.0)            |
| Templating       | Liquid                                |
| Markup           | HTML5                                 |
| Styling          | CSS3 / SCSS (modular + BEM-inspired)  |
| Interactivity    | Vanilla JavaScript (ES6+), AJAX Cart & Search APIs |
| Performance      | Lazy loading, AVIF/WebP images, critical CSS, font optimization |
| Animations       | Native CSS transitions + lightweight JS where required |
| Development      | Shopify CLI                           |
| Accessibility    | Semantic HTML, ARIA attributes, keyboard/touch support |
